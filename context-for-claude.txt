JS CONVENTIONS
- frame({top, a, b, main, bottom}) renders [top row][zone A][zone B][bottom row],
  or a single centred "main" block. Classes: .frame .toprow .bottomrow .main
  .slotA (33%) .slotB (rest) .zone .panel .big-msg .zone-label
- transitionTo(fn): 250 ms fade-out, swap, 350 ms fade-in (CSS .fade-out/.fade-in)
- Data: fetch JSON once, shuffle() the array, play rounds in order without
  repeats; results[] stores {label, score, total, seconds, moves, helps, metric}
- Per-round stats (time, moves, helps) reset each round; the summary sums them
- Summary rows use textContent (never innerHTML) for data from the JSON
- Metric = % correct per round; final score = average, clamped 0-100
- Phases per round: intro -> study (timer, 45 s) -> play -> result -> next/done
- Screen-specific tweaks are done with .frame:has(#btn-xxx) selectors
